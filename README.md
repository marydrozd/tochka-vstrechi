# tochka-vstrechi

Сервис, который строит прогулку по Москве под интересы человека.

## Как работает
1. Пользователь проходит опрос интересов
2. Выбирает, с кем гуляет, время, бюджет и тип прогулки
3. Получает готовый маршрут на Яндекс Карте
4. После прогулки оценивает места, и следующие маршруты становятся точнее

## Технологии
- HTML, CSS, JavaScript
- API Яндекс Карт
- (в планах) Python-бэкенд и ИИ
