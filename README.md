# ТочкаВстречи (tochka-vstrechi)

Сайт, который за пару минут собирает пешую прогулку по Москве и Подмосковью под твои интересы, время и бюджет, показывает её на карте и ведёт по маршруту.

**Демо:** https://marydrozd.github.io/tochka-vstrechi/

## Как это работает

1. **Регистрация и опрос интересов.** Вход по email или юзернейму. При регистрации человек даёт согласие на обработку персональных данных и проходит короткий опрос: что любит (парки, вода, искусство, еда, уличные музыканты и т. д.).
2. **Конструктор прогулки.** Пять обязательных вопросов: время, бюджет, темп, с кем гуляешь и точка старта (её можно выбрать на карте). Остальное спрятано в «Ещё настройки»:
   - **«Куда обязательно зайти?»** — место, которое точно попадёт в маршрут;
   - **«Готов(а) проехать на метро?»** — если да, маршрут начинается с твоей точки старта, потом станция, а стоимость проезда вычитается из бюджета;
   - **«Выбрать из друзей»** — учесть интересы друга, с которым идёшь гулять.
   Есть и «Быстрая прогулка» без лишних вопросов.
3. **Подбор мест.** Сайт собирает реальные места из открытых источников, а нейросеть ГигаЧат выбирает лучшие, придумывает название прогулки и комментарий к каждой остановке.
4. **Маршрут на Яндекс Карте.** У каждой остановки указано, сколько там провести времени, сколько денег потратить и чем заняться. Бюджет реально распределяется по остановкам (кафе, музеи и т. п.).
5. **Навигация прямо на сайте.** Подсказки поворотов по геолокации и отметка «пришли», когда ты рядом с точкой.
6. **Отзыв после прогулки.** Кнопка «Завершить прогулку»: оценка от 1 до 5, что понравилось и что нет. Все прогулки сохраняются в «Мои прогулки».
7. **Друзья.** Можно найти друга по юзернейму, добавить его в список и строить прогулки с учётом его интересов.

На странице «О проекте» кратко рассказано, зачем нужен сервис и как им пользоваться.

## Технологии

- **Фронтенд:** HTML, CSS, JavaScript в одном файле `index.html`, хостинг на GitHub Pages.
- **Бэкенд:** [Supabase](https://supabase.com)
  - Auth — регистрация и вход (в том числе по юзернейму);
  - база PostgreSQL — профили, сохранённые прогулки, отзывы, друзья (с политиками доступа RLS);
  - Edge Function `plan-walk` — обращается к ГигаЧату.
- **Нейросеть:** ГигаЧат (Pro, при ошибке — Lite).
- **Карты:** API Яндекс Карт 2.1; запасной пешеходный маршрутизатор OSRM.
- **Источники мест:** data.mos.ru, KudaGo, OpenStreetMap (Overpass API).

## Структура репозитория

| Файл | Что это |
|---|---|
| `index.html` | весь сайт |
| `config.js` | адрес и публичный ключ Supabase (если оставить пустым, сайт работает в демо-режиме, всё хранится в браузере) |
| `logo-animated.svg` | анимированный логотип |
| `plan-walk.ts` | код Edge Function `plan-walk` |
| `gigachat-prompt.md` | промпт для ГигаЧата с примерами |
| `supabase-*.sql` | скрипты для базы: профили, прогулки, вход по юзернейму, отзывы, друзья |

## Как запустить у себя

1. Создать проект в Supabase.
2. В SQL Editor по очереди выполнить: `supabase-setup.sql`, `supabase-walks.sql`, `supabase-login.sql`, `supabase-friends.sql`, `supabase-friends-list.sql`, `supabase-feedback.sql`.
3. Создать Edge Function `plan-walk` с кодом из `plan-walk.ts`. Ключ ГигаЧата и сертификат добавить в **Supabase → Edge Functions → Secrets** (в репозиторий их не кладём).
4. В `config.js` вписать Project URL и публичный (anon / publishable) ключ Supabase.
5. Включить GitHub Pages для репозитория.

## Персональные данные

Сайт собирает email, юзернейм, ответы опроса, сохранённые маршруты и отзывы. При регистрации пользователь даёт согласие на обработку данных, на сайте есть политика конфиденциальности. Перед публичным запуском планируется перенос данных на сервер в России (по требованиям 152-ФЗ).
